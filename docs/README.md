# Project Documentation

This directory holds the detailed explanation for the MLOps project.

- `concepts.md` explains the MLOps concepts and tool choices.
- `end-to-end-flow.md` follows one model run through data, training, tracking, serving, and deployment.
- `workflows.md` explains how to run the project from setup through inference.
- `project-structure.md` explains each source file, config file, test, and deployment file.
- `artifacts-and-outputs.md` explains generated outputs such as `data/`, `mlruns/`, `models/`, and `reports/`.
- `deployment.md` explains Docker, `kind`, Kubernetes, and MLflow deployment options.
- `portfolio.md` provides resume bullets, interview talking points, and demo steps.

Start with `concepts.md` if you want the big picture. Start with
`workflows.md` if you want to run the project.
