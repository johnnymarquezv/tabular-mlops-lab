# Project Documentation

This directory holds the detailed explanation for the MLOps project.

- `01-concepts.md` explains the MLOps concepts and tool choices.
- `02-end-to-end-flow.md` follows one model run through data, training, tracking, serving, and deployment.
- `03-workflows.md` explains how to run the project from setup through inference.
- `04-project-structure.md` explains each source file, config file, test, and deployment file.
- `05-artifacts-and-outputs.md` explains generated outputs such as `data/`, `mlruns/`, `models/`, and `reports/`.
- `06-deployment.md` explains Docker, OrbStack Kubernetes, and MLflow deployment options.
- `07-portfolio.md` provides resume bullets, interview talking points, and demo steps.

Start with `01-concepts.md` if you want the big picture. Start with
`03-workflows.md` if you want to run the project.
